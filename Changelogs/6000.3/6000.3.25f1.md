### 6000.3.25f1 Release Notes

#### Improvements

- Build System: Updated the bundled 7-Zip to version 26.03.



#### Changes

- Android: Updated the Gradle version shipped with the Editor from 9.1.0 to 9.3.1.



#### Fixes

- Android: Fixed an issue where the input field caret moved back to the end of the text when typing.
    ([UUM-121294](https://issuetracker.unity3d.com/issues/android-ios-the-input-field-caret-moves-back-to-the-end-of-the-text-when-typing))

- Android: Fixed bidirectional synchronization between the virtual keyboard and UGUI textfield.
    (UUM-133870)

- Android: Fixed editText setText resets the IME's internal cursor to end-of-text, independently of the EditText's selection.
    (UUM-142513)

- Android: Fixed `TouchScreenKeyboard.selection.length` always returning `0`.
    ([UUM-125821](https://issuetracker.unity3d.com/issues/android-touchscreenkeyboard-dot-selection-dot-length-always-returns-0-when-any-length-text-is-selected))

- Android: SystemInfo.processorModel and SystemInfo.processorManufacturer now return unknown on Android API levels below 32 instead of a warning string, matching the behaviour on other platforms.
    (UUM-150389)

- Audio: Fixed audiomixer fader clicking in playmode.
    ([UUM-150250](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150250))

- Audio: The Editor no longer logs an error when the audio output device fails to re-initialize while resuming the output after a period of silence. The output now stays suspended, a warning is logged, and the resume is retried the next time audio is used. Also fixed a potential crash on Editor shutdown when the output could not be resumed.
    (UUM-115959)

- Build System: Fixed the IL2CPP Analytics tool exiting with a JsonException after a successful build when the system clock moved backwards during the build.
    ([UUM-150019](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150019))

- Editor: Fixed mesh particles rendering with incorrect UVs \(and other vertex channels\) when the source mesh used a non-float vertex format such as 8-bit UNorm.
    ([UUM-141864](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141864))

- Editor: Fixed Undo/Redo for "GPU Instancing" and "Double Sided Global Illumination" fields for Materials in Inspector.
    ([UUM-143569](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-143569))

- IMGUI: Reduced GC allocations when a GUISkin style is assigned during OnGUI.
    ([UUM-134155](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-134155))

- Linux: Fixed the Editor hanging on the splash screen when a dialog opened while a scene was loading.
    ([UUM-151324](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151324))

- Particles: Fixed Camera Fade OFF + Soft Particles ON combination making particles disappear on some devices.
    ([UUM-146249](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-146249))

- Player: Added guard to avoid hitting a debug assert in dev player builds.
    (UUM-152365)

- Profiler: Fixed a NullReferenceException thrown when saving Profiler data from the top menu of the Standalone Profiler window after toggling the UI Toolkit Live Reload option.
    ([UUM-150706](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150706))

- Scripting: Resolve hang during compilation.
    (UUM-126023)

- SRP Core: Fixed render passes not being merged on older iOS devices \(Apple GPU family 3 and below\) once a native pass was considered to be over the on-tile pixel storage limit, which serialized the whole frame into one native pass per render pass.
    ([UUM-148865](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-148865))

- Text: Fixed infinite loop in text measure with hyphen preceded by whitespace.
    ([UUM-144559](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-144559))

- Text: Fixed stale font faces after source Font unload/reload.
    (UUM-150877)

- TextCore: Fixed a potential crash that would occur when generating a font asset in the Font Asset Creator.
    ([UUM-125366](https://issuetracker.unity3d.com/issues/crash-on-unity-ft-load-glyph-when-generating-multi-threaded-font-atlas-in-tmpro-font-asset-creator))

- TextCore: Fixed a potential crash that would occur when generating a font asset in the Font Asset Creator.
