### 6000.3.27f2 Release Notes

#### Improvements

- Asset Import: Improved the security of model import by updating the bundled Autodesk FBX SDK to 2020.3.11, addressing two buffer-overflow vulnerabilities in FBX file parsing.
    (UUM-155199)



#### API Changes

- Graphics: Added: Added Graphics.disableDepthAndStencilBuffers, a read-only property that returns whether Disable Depth and Stencil Buffers is enabled in Player Settings.



#### Changes

- Physics 2D: "PhysicsComposer.AddLayer", "PhysicsComposer.ToPolygons", "CircleGeometry.ToPolygons" and "CapsuleGeometry.ToPolygons" now log the standard validation warning instead of throwing "ArgumentOutOfRangeException" when given no geometry, fewer than three vertices or an invalid "curveStride".
    ([UUM-156367](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-156367))
