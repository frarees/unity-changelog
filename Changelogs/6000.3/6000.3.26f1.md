### 6000.3.26f1 Release Notes

#### Features

- Editor: Re-Adding the Linux Headless Simulation build target for Simulation Pro clients



#### Changes

- Android: Updated the Android Gradle Plugin \(AGP\) version from 9.0.0 to 9.1.1.



#### Fixes

- 2D: Fix TilemapRenderer flicker when editing Grid Selection scale/rotation
    ([UUM-146002](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-146002))

- 2D: Fixed 2D Renderer upscaling using incorrect viewport size
    ([UUM-151621](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151621))

- 2D: Fixed an issue where `Tilemap.tilemapPositionsChanged` and `tilemapTileChanged` callbacks didn't invoke when `SetTiles` changed only the transform or color of a tile.
    (UUM-146094)

- 2D: Fixed an issue where `TilemapRenderer` inherited normal maps from other Tiles when a Tile did not have a normal map.
    ([UUM-145359](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-145359))

- 2D: Fixed the camera sorting layer texture resolution being affected by the Render Scale setting on the 2D Renderer.
    ([UUM-151723](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151723))

- 2D: Fixed the Open Tile Palette button and Tilemap Focus dropdown not filling the full width of their Scene view overlay.
    ([UUM-151417](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151417))

- Android: Fix "Failed to find target with hash string android-37" when Target API Level 37 is selected.
    ([UUM-150216](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150216))

- Asset Bundles: Fixed a player crash when instantiating a prefab from an AssetBundle that was reached through a reference to a child object of a prefab in another AssetBundle.
    (UUM-141605)

- Build Pipeline: Fixed sequential command line builds started with -activeBuildProfile compiling scripts for the previously active platform.
    (UUM-150775)

- Editor: Don't optimize the projection matrix when Vulkan pre-transform may rotate it
    ([UUM-150650](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150650))

- Editor: Fixed a bug where the Linux Editor wasn't anchoring the Help and Window menus to the end of the main menu bar.
    (UUM-113169)

- Editor: Fixed a deadlock when exiting Play Mode while asynchronous shader compilation was still in progress on Direct3D12.
    ([UUM-152966](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152966))

- Editor: Fixed account dropdown display when entering play mode
    ([UUM-150759](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150759))

- Editor: Fixed an issue where switching back to a Windows Build Profile with Intel 32-bit architecture could leave the active build target as Intel 64-bit \(StandaloneWindows64\) instead of Intel 32-bit \(StandaloneWindows\).
    ([UUM-143128](https://issuetracker.unity3d.com/issues/windows-platform-architecture-switching-from-intel-32-bit-to-intel-64-bit-in-backend-when-switching-active-build-profile-back-to-windows-from-any-other-platform))

- Editor: Fixed the Editor crashing when pressing Cmd+Q more than once while the "Scene\(s\) Have Been Modified" dialog is displayed.<br>
    Fixed two "Scene\(s\) Have Been Modified" dialogs being displayed when quitting the Editor in Play Mode with unsaved changes.<br>
    Fixed the Editor crashing on quit when a script subscribed to EditorApplication.quitting modified an Editor window.<br>
    Fixed the Escape key not selecting Cancel in Editor dialogs.
    ([UUM-149668](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149668))

- GI: Fix a bug where APV bake fails when scene contains a VFXRenderer.
    ([UUM-150965](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150965))

- Graphics: Fixed an issue that could cause memory leak warnings, primarily on macOS, while Unity processed shader jobs with GPU Resident Drawer enabled.
    ([UUM-140185](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-140185))

- IMGUI: Fixed text fields not scrolling to keep the cursor visible when typing text longer than the visible field width, such as when renaming an asset in the Project window.
    ([UUM-149213](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149213))

- iOS: Fix keyboard sometimes closing when switching between TMP input fields with the same parameters.
    (UUM-149104)

- macOS: Fixed the macOS Editor ignoring internal tick requests while its window was unfocused, which made async and coroutine-based execution run slower than when focused.
    (UUM-151097)

- N/A \(internal\): Fixes linear rendering for Unity Render Service for Android
    (UUM-129914)

- Networking: Fixed UnityWebRequest cookies occasionally reverting to an older value when a slower request completed after a faster concurrent request to the same host had already set a newer cookie.
    ([UUM-150958](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150958))

- Networking: UnityWebRequest: Fixed a freeze when quitting a standalone player while an ongoing request was still resolving DNS against an unresponsive or slow DNS server.
    ([UUM-151643](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151643))

- Player: GameObjects cast correct shadows after Shader.globalMaximumLOD is changed at runtime.
    ([UUM-150226](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150226))

- Profiler: Fixed a NullReferenceException thrown when saving an empty Standalone Profiler recording.
    ([UUM-150588](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150588))

- Profiler: Fixed labelling of Unrooted Allocations associated with GraphicsStateCollection Allocations.
    ([UUM-139555](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-139555))

- Profiler: Fixed the Troubleshoot Connection Issues button in the Profiler linking to a documentation page unrelated to connection troubleshooting.
    ([UUM-153354](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153354))

- Shaders: Fixed a crash due to an out-of-range value being supplied to Shader global property APIs.
    ([UUM-150856](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150856))

- Terrain: Fixed a crash when loading a Terrain whose heightmap resolution exceeds the maximum render texture size of the device, for example a 4097 heightmap on a device limited to 4096.
    ([UUM-150551](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150551))

- Text: Fixed multi-paragraph auto-sized text collapses to an elided first line instead of shrinking to fit.
    (UUM-150602)

- uGUI: Fixes compiler warnings from the unnecessary keyword 'new' in WorldDocumentRaycaster.camera.
    ([UUM-151722](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151722))

- UI Toolkit: Fixed a VisualElement with the DynamicTransform usage hint remaining invisible until hovered after an ancestor's scale animated up from zero, when another ancestor used the GroupTransform usage hint.
    ([UUM-140869](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-140869))

- UI Toolkit: Fixed SVG gradients xlink:href inheritance.
    ([UUM-150193](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150193))

- UI Toolkit: Fixed SVG import errors with nested svg tags.
    ([UUM-150948](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150948))

- URP: Fix a bug where reloading a scene would cause certain `Blitter` functions to stop working.
    (UUM-153092)

- URP: Fix shadergraph compilation failure on uv4 input semantic differences.
    ([UUM-143884](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-143884))

- URP: Fixes a bug where seams appear on box projected reflection probes on platforms with half precision \(mobile\).
    ([UUM-141981](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141981))

- URP: Improved GPU performance for URP projects on tile-based platforms by avoiding unnecessary color loads when UberPost \(post-processing\) is the final pass.
    (UUM-140408)

- Web: Fixed Web platform build when output asset sizes are larger than 2 GB, and the build error message if output asset sizes are larger than 4 GB \(unsupported\).
    ([UUM-112909](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-112909))
