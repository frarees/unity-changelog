### 6000.5.11f1 Release Notes

#### Fixes

- 2D: Fixed error message when entering fast playmode with Sprite Editor Window changes.
    ([UUM-146790](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-146790))

- Audio: Bug was already fixed. Added a test.
    ([UUM-147800](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147800))

- Audio: Fixed crash when pausing AudioRandomContainer containing streaming clips that are still loading.
    (UUM-148440)

- Audio: Fixed invalid LoadState in some audio clips after Audio Settings reset.
    ([UUM-147700](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147700))

- Code Editor: Fixed the "Reset argument" button in Preferences &gt; External Tools so it updates the "External Script Editor Args" field immediately instead of only after a focus change.
    (UUM-150210)

- DX12: Start tracking d3d12 resources using D3D12Object class on remaining D3D12 platforms similarly to how desktop does this.
    (UUM-147469)

- Editor: Fixed an Editor crash that occured when inspecting a TextMeshPro font asset.
    ([UUM-145753](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-145753))

- Editor: Fixed an issue where accessing the rootVisualElement of an Overlay's container could cause recursive calls and crash the Editor.
    ([UUM-149209](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149209))

- Editor: Fixed an issue where scripts were not being created after pressing **Enter** in the INspector's Add Component New Script view.
    ([UUM-149682](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149682))

- Editor: Fixed bug in scripting defines where reverting an un-applied change when a build profile loses focus should not cause a domain reload.
    ([UUM-149532](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149532))

- Editor: Fixed floating Video Clip Inspector preview error and cosmetic warning.
    ([UUM-147192](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147192))

- Editor: Fixed HDRP contact shadows quantizing to 2x2 pixel blocks at full resolution.
    ([UUM-150212](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150212))

- Editor: Reinstate 2 Project Auditor analyzers that will not be migrated to the Rules package.
    (UUM-150288)

- Editor: Removed the "Missing or broken path\(\)" message displayed in the 'Open Recent Scene' dropdown on a newly created project. \(\[UUM-113848\]\(https://jira.unity3d.com/browse/UUM-113848\)\).
    ([UUM-113848](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-113848))

- Editor: Search : Fixed "Non-matching Profiler.EndSample" error is thrown for "SearchImporter.IndexingRequest" when creating a script with Edit Mode Profiler recording enabled.
    ([UUM-143780](https://issuetracker.unity3d.com/issues/non-matching-profiler-dot-endsample-error-is-thrown-for-searchimporter-dot-indexingrequest-when-creating-a-script-with-edit-mode-profiler-recording-enabled))

- GI: Fixed a crash when opening the Profiler \(Standalone Process\) window in projects created from templates that include the Tutorials framework.
    ([UUM-149676](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149676))

- Netcode for Entities: Fixed a predicted ghost divergence caused by running at very high framerates with very low SimulationTickRate, which meant that the client to not even fully predict one tick ahead of the latest snapshot arrival, causing the snapshot to be applied on a partial tick, which in turn resulted in the prediction-history backup failing to write, so it would constantly be stale.
    (UUM-147343)

- Physics: Fixed an issue inside the PhysX 4 sdk, where CharacterController wouldn't be able to collide with more than 100 shapes at a time.
    ([UUM-132204](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-132204))

- Physics: Improved the cleanup performance of IgnoreCollision when destroying a Collider.
    ([UUM-115186](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-115186))

- Physics 2D: Applying a very large wind force via `PhysicsBody.ApplyWind`, or a very large impulse via `PhysicsWorld.Explode`, could silently corrupt the entire physics world with NaN or Infinity values.
    ([UUM-150029](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150029))

- Physics 2D: Wake Rigidbody2D when activating a child GameObject containing a Collider2D.

- Physics 2D: `PhysicsWorld` could crash or corrupt memory when created with a very large or negative `PhysicsWorldDefinition.capacity`.

- SRP Core: Fixed an assertion error and memory leak warning that were thrown when hiding a branch group on a Tree in a project that uses the GPU Resident Drawer.
    ([UUM-142959](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-142959))

- Terrain: Fixed the Editor hanging when painting terrain details in Coverage mode with a very small Min Width and Max Width, or with a detail mesh that is very thin along one axis.
