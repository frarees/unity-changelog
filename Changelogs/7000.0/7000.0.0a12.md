### New 7000.0.0a12 Entries since 7000.0.0a11

#### Features

- Animation: Added named animatable channels for script components. A MonoBehaviour exposes channels by declaring a serialized field of type AnimatableFloatChannels, AnimatableIntChannels or AnimatableObjectChannels.

- Build Pipeline: Added a Referenced By tree to the Build Analysis asset inspector, which shows which assets reference the selected asset and the paths from each of them up to the build's loadable roots.

- Editor: Introduce BuildProfilePostprocessBuild component so users can add postprocess build callbacks to build profiles that will run for the active build profile being built.

- Package Manager: When Closed Network users enable the Closed Network-exclusive Project Setting to disable Trust messaging on packages, all packages are considered Out of Trust.

- UI Toolkit: Added the box-shadow USS property, with outer and inset shadows, blur and spread radii, transitions, and UI Builder and Inspector support.



#### Improvements

- Build Pipeline: Section headers in the Build Analysis window now highlight across their full width when hovered.

- Burst: Improved the layout of the Burst Inspector window, with clearer toolbars and output tabs and a search bar that is always shown. Also added a function dropdown to the Burst Inspector that jumps to a function in the disassembly, and Previous and Next buttons to step through search matches.

- Editor: Improved the description of what's contained in the Multiplayer sample install flow.

- IL2CPP: Fixed static field accesses not throwing an exception when a class's cctor failed on some platforms.

- IL2CPP: Volatile fields and the `volatile.` prefix use acquire and release semantics instead of a full memory barrier.

- Mono: Reduced JIT compile overhead by skipping JIT phase timing when runtime statistics are disabled.

- Scripting: The "Managed Stack Trace Information" setting now affects stack traces printed from Burst code.

- UI Toolkit: Improved style resolution performance when many elements share the same cached styles.

- UI Toolkit: Improved the performance of pointer event dispatch, especially when the pointer moves between deeply nested elements.

- UI Toolkit: Removed the per-restyle managed allocations for elements whose UXML inline style declares custom properties \(USS variables\).

- UI Toolkit: UI Builder no longer searches the whole project after every UXML or USS change when no UI Builder window is open.



#### API Changes

- Animation: Added: Added AnimatableFloatChannels, AnimatableIntChannels and AnimatableObjectChannels.

- Editor: Added: Added the BuildProfilePlayerSettings component, so that you can create, get, and remove a build profile's own player settings with BuildProfile.CreateComponent, GetComponent, and RemoveComponent.

- Engine Diagnostics: Changed: EngineDiagnosticsSettings.enabled now reads and writes the Diagnostic Data Collection setting of the active build profile, or of the active platform profile if no build profile is active, and doesn't change other build profiles. To disable Diagnostic Data Collection for all users and CI, set it to Disabled in a build profile asset, commit the asset, and build with that profile by using -activeBuildProfile or BuildPipeline.BuildPlayer with BuildPlayerWithProfileOptions.

- Physics 2D: Added: Added "PhysicsQuery.CircleAndCapsule", "PhysicsQuery.CircleAndSegment", "PhysicsQuery.CircleAndPolygon", "PhysicsQuery.CapsuleAndSegment", "PhysicsQuery.CapsuleAndPolygon" and "PhysicsQuery.PolygonAndSegment" so every pair of geometries can be queried in either order.
    ([UUM-157419](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-157419))

- Physics 2D: Deprecated: Deprecated the "useScale" parameter of "PhysicsMath.GetRelativeMatrix2D", which had no effect; use the overload without it, or "PhysicsMath.GetRelativePose2D" to build a matrix with the scale you need.
    ([UUM-157407](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-157407))

- Terrain: Added: Added `TerrainData.maxHeightmapResolution`, `minAlphamapResolution`, `maxAlphamapResolution`, `minBaseMapResolution`, `maxBaseMapResolution`, `minDetailResolutionPerPatch` and `maxDetailResolutionPerPatch`, the limits that the resolution setters clamp values to.

- Terrain: Added: Added `TerrainRegion` and `TerrainEditUtility` to sculpt heights and paint terrain layers by height and slope inside a rectangle, disc or path from scripts, and to read the heightmap samples and alphamap texels such an area covers. They are designed for authoring.

- uGUI: Changed: Selectable.s_Selectables changed from a Selectable array to List&lt;Selectable&gt;.

- uGUI: Obsoleted: Selectable.s_SelectableCount is now obsolete. Use Selectable.allSelectableCount instead.

- UI Toolkit: Added: Added the BoxShadow and StyleBoxShadow types, and the IStyle.boxShadow and IResolvedStyle.boxShadow properties.



#### Changes

- Engine Diagnostics: Diagnostic Data Collection is now enabled by default for every build profile, including in upgraded projects, unless a build profile explicitly disables it.

- Engine Diagnostics: Diagnostic data is no longer collected in the Editor when the active build profile targets a platform that doesn't support Diagnostics.

- Engine Diagnostics: Editor crash and exception reporting to Diagnostics now follows the Diagnostic Data Collection setting of the active build profile.

- Engine Diagnostics: Removed the Diagnostics page from Project Settings &gt; Services. Diagnostic Data Collection is now configured for each build profile in the Build Profiles window, and Project Settings &gt; Services describes the diagnostic data that Unity collects.

- Engine Diagnostics: The Diagnostic Data Collection setting in the Build Profiles window now offers Enabled and Disabled, and disabling it no longer asks for confirmation.
