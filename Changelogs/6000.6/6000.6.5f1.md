### 6000.6.5f1 Release Notes

#### Fixes

- 2D: Fixed the camera sorting layer texture resolution being affected by the Render Scale setting on the 2D Renderer.
    ([UUM-151723](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151723))

- Android: Fixed system bars not hiding automatically on Android 11 when System Bars Behavior is set to "Show Transient Bars By Swipe".
    ([UUM-149900](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149900))

- Asset Bundles: Fixed a player crash when instantiating a prefab from an AssetBundle that was reached through a reference to a child object of a prefab in another AssetBundle.
    (UUM-141605)

- Asset Pipeline: Fixed a crash on Editor shutdown caused by an asset import worker timer callback running after the worker manager was destroyed.
    (UUM-134447)

- Asset Pipeline: Fixed a crash when opening a project with a corrupted Library.
    ([UUM-153198](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153198))

- Asset Pipeline: Fixed a random Editor crash on shutdown caused by a data race in the asset database script artifact bookkeeping.
    (UUM-142994)

- Editor: Fixed a NullReferenceException thrown when selecting a GameObject in the Hierarchy while the Tool Contexts overlay was displayed but collapsed.
    ([UUM-141529](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141529))

- Editor: Fixed Scene Visiblity Update Issue Without a Scene View
    ([UUM-139553](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-139553))

- Editor: Fixed tabs getting stuck when dragging across dock areas
    ([UUM-140149](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-140149))

- Editor: Fixed the undo of a drag and drop operation that moved nodes and opened a prefab at the same time.
    ([UUM-148783](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-148783))

- Editor: Skip post-build audit when Project Auditor Rules package isn't installed
    ([UUM-152518](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152518))

- GI: Fixed light baking failing when the only Global Illumination contributors in a scene had no materials assigned.
    (UUM-153676)

- Graphics: Fix crash when importing Texture2DArrays with small dimensions and many elements
    ([UUM-153670](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153670))

- macOS: Fixed the macOS Editor ignoring internal tick requests while its window was unfocused, which made async and coroutine-based execution run slower than when focused.
    (UUM-151097)

- Multiplayer: Fixing the scaling artifacts of the Multiplayer Center window's genre titles in Bitmap rendering mode.

- Multiplayer: Unity Transport: Correctly recreate UDP sockets on iOS when they are closed by the OS when an application is in the background for a while. Prevents a condition when the driver seemingly stops receiving packets.
    ([UUM-153993](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153993))

- Package Manager: Fixed exporting a signed .unitypackage failing with "IOException: Stream was too long." when the uncompressed package content exceeded 2 GB, and reduced Editor memory usage during package export and signing.
    ([UUM-153848](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153848))

- Profiler: Fix Profiler details view potentially showing info for frames that are no longer present in the timeline.
    ([UUM-150694](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150694))

- Profiler: Fixed an inconsistent seam line between the image and frame number on Profiler Screenshots module thumbnails.
    ([UUM-152561](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152561))

- Profiler: Fixed frame-number labels overlapping in the Screenshots module's timeline view when Game View captures used a narrow aspect ratio.
    ([UUM-152532](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152532))

- Profiler: Fixed the Profiler capture rename field discarding the first click and re-selecting the whole name instead of placing the caret.
