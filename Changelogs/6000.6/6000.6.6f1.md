### 6000.6.6f1 Release Notes

#### Fixes

- 2D: Fixed ArgumentException when using overlay camera in 2D Renderer.
    ([UUM-148111](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-148111))

- 2D: Fixed intermediate texture not created when requested by render pass.
    ([UUM-145892](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-145892))

- 2D: Fixed LineRenderer not initializing correctly when toggling enable on game object.
    ([UUM-147747](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147747))

- 2D: Fixed NaN warning in sprite intermediate renderer.
    ([UUM-147102](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147102))

- 2D: Fixed Render Objects feature failing when depth buffer is disabled.
    ([UUM-153342](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153342))

- Android: Fixed freeze when relaunching GameActivity immediately after unload in UaaL mode.
    (UUM-149857)

- Android: Fixed Target API Level not being properly selected from dropdown.
    ([UUM-154841](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154841))

- Animation: Fixed an issue where clicking in the "Edit Key" fields of the Animation Window curve view wouldn't deselect the text in the field.
    ([UUM-140166](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-140166))

- Asset Pipeline: Fixed a crash when opening a project that contained a manager asset holding an object of the wrong type.
    ([UUM-153271](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153271))

- Asset Pipeline: Fixed an issue where the Editor could crash during a domain reload or on quit while asset previews were loading.
    ([UUM-141036](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141036))

- Editor: Fixed a MissingReferenceException that the Inspector logged on Play mode exit when it was scrolled down and showed a Volume component.
    ([UUM-153587](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153587))

- Editor: Fixed GameObjects with HideAndDontSave hide flags not disappearing immediately from the Hierarchy window when the flag was changed through an Inspector property edit.
    ([UUM-150345](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150345))

- Editor: Hierarchy no longer shows as empty when returning from editing a nested prefab to it's parent, after the parent prefab was edited on disk.
    ([UUM-154347](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154347))

- Editor: OnCodeLoaded Scripting API documentation updated.
    (UUM-155081)

- Entities: Fixed an issue where rebuilding an unchanged project produced different content archives, causing published remote content to be downloaded again.
    ([UUM-151571](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151571))

- Entities: Fixed an issue where the authoring representation of an object would be shown instead of the runtime representation, when selecting the object through Entities Hierarchy.
    ([UUM-152665](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152665))

- Entities: Fixed GameObjects in an open SubScene disappearing from the Hierarchy window after the SubScene GameObject was disabled and enabled.
    ([UUM-154731](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154731))

- Entities: Fixed the entity list foldout under a SubScene in the Hierarchy collapsing after an undo of reordering or reparenting SubScenes.
    ([UUM-147837](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147837))

- GI: Fixed Editor crashes when building a GPU BVH from an empty primitive span or with a maxLeafSize of 0.
    ([UUM-154597](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154597))

- Graphics: `Screen.currentBackbufferMSAASamples` on Android Vulkan now correctly returns the MSAA sample value of the back buffer.

- IMGUI: Fixed the text cursor being vertically misaligned in an empty text field.
    ([UUM-145875](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-145875))

- macOS: Fixed a crash on recent macOS versions that could occur when importing X.509 certificates.
    (UUM-154511)

- Scripting: Fixed an issue where opening the Standalone Profiler could trigger a script compilation in the Profiler process, which logged "Could not find a part of the path" errors for package assemblies.
    (UUM-133483)

- Source Code Build: Fixed Editor source builds failing on machines that use the Turkish region format.
    (UUM-154501)

- SRP Core: Fixed rendering corruption when using async compute with Render Graph, where a texture could be used from both the graphics and compute queues simultaneously.
    ([UUM-141896](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141896))

- Text: Fixed an out-of-bounds memory read when a TextMesh or legacy UI Text string ended with an unterminated quad tag parameter.
    (UUM-153129)

- Text: Fixed an out-of-bounds memory read when a TextMesh or legacy UI Text string ended with an unterminated rich text tag.
    (UUM-153128)

- UI Toolkit: Fixed a NullReferenceException in the Inspector when saving a UI Toolkit element animation while the Animation window is in Preview mode.
    ([UUM-155268](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-155268))

- UI Toolkit: Fixed a NullReferenceException when a z-index child inside an element rendered through a render texture had an ancestor whose scale changed from 1.
    (UUM-152805)

- UI Toolkit: Fixed an issue where undoing the deletion of a selector in the Style Sheets window restored it at the wrong position.
    ([UUM-149380](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149380))

- UI Toolkit: Fixed blurred text and content in elements with a filter, such as drop-shadow, when the panel scale is not a whole number.
    ([UUM-155009](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-155009))

- UI Toolkit: Fixed element animations playing in the Game View while the Editor is in Edit Mode.
    ([UUM-148584](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-148584))

- UI Toolkit: Fixed elements with a 3D rotation or Z offset disappearing on overlay panels when they are rendered through a dynamic or group transform.
    (UUM-145649)

- UI Toolkit: Fixed elements with the GroupTransform usage hint, such as a ScrollView content container, rendering at the wrong position and logging an assertion after an ancestor's scale changed from 1.
    (UUM-152805)

- UI Toolkit: Fixed instable UGUIEventSystemTests on WindowsEditor.
    (UUM-143303)

- UI Toolkit: Fixed multi-column list and tree views requiring Ctrl+click instead of Cmd+click to sort by multiple columns in Web builds running on macOS.

- UI Toolkit: Fixed SliderInt thumb position, dragging, keyboard stepping, and value display when the slider range uses values near the minimum or maximum integer limits.
    ([UUM-154562](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154562))

- UI Toolkit: Fixed the action key of pointer, mouse, keyboard and navigation events being Ctrl instead of Cmd in Web builds running on macOS.
    ([UUM-153940](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153940))

- UI Toolkit: Fixed the Dynamic Atlas Viewer showing no atlas after the UI Toolkit Debugger window was recreated, such as when maximizing and restoring a docked window or toggling UI Toolkit Live Reload on the debugger.
    ([UUM-150663](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150663))

- UI Toolkit: Fixed the Editor and Players hanging when a USS transition-timing-function declaration uses a value that is not a keyword, such as 5px.
    ([UUM-155159](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-155159))

- UI Toolkit: Fixed the Gradient Editor clearing the redo history and adding an empty Modify Gradient undo step when it closed after an undo.
    ([UUM-153510](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153510))

- UI Toolkit: Fixed the Select GameObject window silently ignoring Prefab picks in a second Inspector after swapping between Prefabs with different components.
    ([UUM-154149](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-154149))

- URP: Reduced back buffer memory and bandwidth on platforms with a multisampled back buffer including Android, iOS, and Metal. The back buffer remains single-sampled in frames where no camera renders MSAA directly to it, for example a camera that resolves MSAA from an intermediate texture. MSAA results are unaffected.
    (UUM-134600)
