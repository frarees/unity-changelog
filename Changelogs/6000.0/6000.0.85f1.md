### 6000.0.85f1 Release Notes

#### Improvements

- Build System: Updated the bundled 7-Zip to version 26.03.



#### API Changes

- Graphics: Added: Added Graphics.disableDepthAndStencilBuffers, a read-only property that returns whether Disable Depth and Stencil Buffers is enabled in Player Settings.



#### Changes

- Android: Updated the Android Gradle Plugin \(AGP\) version from 9.0.0 to 9.1.1.



#### Fixes

- 2D: Fixed ArgumentException when using overlay camera in 2D Renderer.
    ([UUM-148111](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-148111))

- 2D: Fixed error message when entering fast playmode with Sprite Editor Window changes.
    ([UUM-146790](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-146790))

- 2D: Fixed intermediate texture not created when requested by render pass.
    ([UUM-145892](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-145892))

- 2D: Fixed LineRenderer not initializing correctly when toggling enable on game object.
    ([UUM-147747](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-147747))

- 2D: Fixed the camera sorting layer texture resolution being affected by the Render Scale setting on the 2D Renderer.
    ([UUM-151723](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151723))

- Android: Fixed "Failed to find target with hash string android-37" when Target API Level 37 is selected.
    ([UUM-150216](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150216))

- Android: Fixed an issue where the input field caret moved back to the end of the text when typing.
    ([UUM-121294](https://issuetracker.unity3d.com/issues/android-ios-the-input-field-caret-moves-back-to-the-end-of-the-text-when-typing))

- Android: Fixed bidirectional synchronization between the virtual keyboard and UGUI textfield.
    (UUM-133870)

- Android: Fixed editText setText resets the IME's internal cursor to end-of-text, independently of the EditText's selection.
    (UUM-142513)

- Android: Fixed freeze when relaunching GameActivity immediately after unload in UaaL mode.
    (UUM-149857)

- Android: Fixed `TouchScreenKeyboard.selection.length` always returning `0`.
    ([UUM-125821](https://issuetracker.unity3d.com/issues/android-touchscreenkeyboard-dot-selection-dot-length-always-returns-0-when-any-length-text-is-selected))

- Asset Bundles: Fixed a player crash when instantiating a prefab from an AssetBundle that was reached through a reference to a child object of a prefab in another AssetBundle.
    (UUM-141605)

- Audio: Fixed a bug on macOS where audio playback would slow down when the microphone was being used by the system.
    ([UUM-149880](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149880))

- Editor: Fixed a bug where the Linux Editor wasn't anchoring the Help and Window menus to the end of the main menu bar.
    (UUM-113169)

- Editor: Fixed a deadlock when exiting Play Mode while asynchronous shader compilation was still in progress on Direct3D12.
    ([UUM-152966](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-152966))

- Editor: Fixed an issue where accessing the rootVisualElement of an Overlay's container could cause recursive calls and crash the Editor.
    ([UUM-149209](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149209))

- Editor: Fixed the Editor crashing when pressing Cmd+Q more than once while the "Scene\(s\) Have Been Modified" dialog is displayed.<br>
    Fixed two "Scene\(s\) Have Been Modified" dialogs being displayed when quitting the Editor in Play Mode with unsaved changes.
    ([UUM-149668](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-149668))

- Graphics: Fixed Graphics.RenderPrimitives and Graphics.DrawProcedural crash with MeshTopology.Quads when Graphics Jobs are enabled.
    ([UUM-141117](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141117))

- macOS: Fixed a crash on recent macOS versions that could occur when importing X.509 certificates.
    (UUM-154511)

- Multiplayer: Unity Transport: Fixed a memory leak when closing connections using DTLS or TLS.
    ([UUM-151755](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151755))

- Networking: Fixed UnityWebRequest cookies occasionally reverting to an older value when a slower request completed after a faster concurrent request to the same host had already set a newer cookie.
    ([UUM-150958](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150958))

- Networking: UnityWebRequest: Fixed a freeze when quitting a standalone player while an ongoing request was still resolving DNS against an unresponsive or slow DNS server.
    ([UUM-151643](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151643))

- Particles: Fixed Camera Fade OFF + Soft Particles ON combination making particles disappear on some devices.
    ([UUM-146249](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-146249))

- Player: Added guard to avoid hitting a debug assert in dev player builds.
    (UUM-152365)

- Player: GameObjects cast correct shadows after Shader.globalMaximumLOD is changed at runtime.
    ([UUM-150226](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150226))

- Profiler: Fixed the Troubleshoot Connection Issues button in the Profiler linking to a documentation page unrelated to connection troubleshooting.
    ([UUM-153354](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153354))

- Shaders: Fixed a crash due to an out-of-range value being supplied to Shader global property APIs.
    ([UUM-150856](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150856))

- Source Code Build: Fixed Editor source builds failing on machines that use the Turkish region format.
    (UUM-154501)

- Terrain: Fixed a crash when loading a Terrain whose heightmap resolution exceeds the maximum render texture size of the device, for example a 4097 heightmap on a device limited to 4096.
    ([UUM-150551](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150551))

- Text: Fixed an out-of-bounds memory read when a TextMesh or legacy UI Text string ended with an unterminated quad tag parameter.
    (UUM-153129)

- Text: Fixed an out-of-bounds memory read when a TextMesh or legacy UI Text string ended with an unterminated rich text tag.
    (UUM-153128)

- UI Toolkit: Fixed multi-column list and tree views requiring Ctrl+click instead of Cmd+click to sort by multiple columns in Web builds running on macOS.

- UI Toolkit: Fixed the action key of pointer, mouse, keyboard and navigation events being Ctrl instead of Cmd in Web builds running on macOS.
    ([UUM-153940](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-153940))

- Universal Windows Platform: Fixed an issue on Xbox where confirming the on-screen keyboard cleared the text field instead of keeping the typed text.
    (UUM-154127)

- Universal Windows Platform: Fixed an issue on Xbox where pressing B to close the on-screen keyboard kept the typed text instead of reverting to the previous value.
    (UUM-149423)

- URP: Fixed a bug where reloading a scene would cause certain `Blitter` functions to stop working.
    (UUM-153092)

- URP: Fixed a bug where seams appear on box projected reflection probes on platforms with half precision \(mobile\).
    ([UUM-141981](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-141981))

- URP: Fixed RenderTexture.Create failure on certain Android Vulkan devices.
    ([UUM-91313](https://issuetracker.unity3d.com/issues/android-vulkan-error-rendertexture-dot-create-failed-format-unsupported-for-random-writes-r16-sfloat-45-dot-logged-when-during-launch-on-an-project-with-urp-2d-renderer))

- URP: Fixed shadergraph compilation failure on uv4 input semantic differences.
    ([UUM-143884](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-143884))

- URP: Fixed the 2D Renderer creating a depth and stencil buffer in players when Disable Depth and Stencil Buffers is enabled in Player Settings.
    ([UUM-150232](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150232))

- URP: ScriptableRendererData.TryGetRendererFeature was throwing NullReferenceException.
    ([UUM-150772](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-150772))

- VFX Graph: Fixed out of bounds accesses occurring when using `MeshToSDFBaker` with certain voxel counts.
    ([UUM-151674](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-151674))

- Web: Fixed WASM_SIZE, wasmFileSize that is used in memory profiler.
    (UUM-149075)

- Web: Fixed Web platform build when output asset sizes are larger than 2 GB, and the build error message if output asset sizes are larger than 4 GB \(unsupported\).
    ([UUM-112909](https://issuetracker.unity.com/api/v1.0/redirects/guid/UUM-112909))
